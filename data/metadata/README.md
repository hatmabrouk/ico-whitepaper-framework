# Metadata

This folder contains the metadata dataset and supporting documentation for the ICO White Paper Framework research project.

## Purpose

The metadata dataset provides descriptive information about each ICO project and corresponding white paper included in the research corpus.

## Example Metadata Fields

- Project Name
- Token Symbol
- Year
- Sector
- Jurisdiction
- Funds Raised (USD)
- Fundraising Type
- White Paper URL
- White Paper Length (Pages)
- Token Type
- Blockchain Platform
- Governance Section Present
- Risk Section Present
- Legal Disclaimer Present
- Roadmap Present
